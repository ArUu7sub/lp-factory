# 読者の悩みをそのまま言語化すると「自分ごと」になる

## 主張
LPで最も重要なのはファーストビューの次のセクション。
読者が「これは自分の話だ」と感じた瞬間に離脱が止まる。

## 型：「こんな悩みありませんか？」
```
こんな気持ち、ありませんか？

□ ○○が難しそうで踏み出せない
□ 何から始めればいいかわからない
□ やってみたけど続かなかった
□ （地域・状況の制約）だと無理かもと思っている
```

## 書き方のポイント
- 読者の言葉で書く（専門用語・業界用語は使わない）
- 「〜ではないですか？」より「〜ありませんか？」の方が柔らかい
- ネガティブな感情を3〜4個並べた後、必ず転換コピーを入れる
- 転換：「その悩み、○○が解決します」「その感覚、正しいです。だからこそ〜」

## 避けること
- 読者を責める書き方（「まだ始めていないんですか？」など）
- 大げさすぎる悩み（実態とかけ離れると不信感が生まれる）
