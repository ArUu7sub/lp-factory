# ベネフィットは機能説明ではなく「読者の変化」で書く

## 主張
読者が知りたいのは「このサービスが何をするか」ではなく「自分がどう変わるか」。
機能を伝えると説明文になり、変化を伝えると共感文になる。

## 書き方の対比
```
× 機能説明：「AIが自動でSNS投稿文を生成します」
○ ベネフィット：「毎日の投稿ネタ探しがなくなり、発信が続くようになる」

× 機能説明：「業務効率化ツールを学べます」
○ ベネフィット：「残業が週3時間減り、副業に使える時間が生まれる」
```

## チェック方法
書いた文章に「だから何？」と問い直す。答えが出るなら、まだ機能説明。
「だから何？」への答えがそのままベネフィット。
