# CTAは1ページ1アクションに絞ると成約率が上がる

## 主張
1枚のLPに複数のアクション（申込・資料請求・LINE登録・SNSフォロー）を並べると、
読者がどれをすればいいか迷い、結果的に何もしない。

## ルール
- **1LP = 1CTA**を徹底する
- ページ内に複数CTAボタンを置く場合も、すべて同じアクションに誘導する
- ボタンのテキストはアクション動詞で始める（「申し込む」「試してみる」「始める」）
- 「詳しくはこちら」「お問い合わせ」のような曖昧な表現は使わない

## 安心コピーをセットで置く
CTAボタンの直下に、ハードルを下げるコピーを置く。
```
例：
「今すぐ入会する」
↓
「いつでも解約できます・違約金なし」
```
