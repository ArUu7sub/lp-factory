# ファーストビューに「誰が・何を・どうなるか」を入れると離脱率が下がる

## 主張
LPのファーストビューには、3秒以内に読者が「これは自分のためのページだ」と判断できる情報を入れる必要がある。

## 構成要素
- **誰が**：ターゲット読者を明示（例：「フリーランスのデザイナー向け」）
- **何を**：サービス・商品の一言説明
- **どうなるか**：読者が得る変化・ベネフィット

## 書き方の例
```
× 「高品質なLP制作サービス」
○ 「3週間で集客LPを公開したい中小企業オーナーへ。受注実績200件のチームが最短で仕上げます」
```
