# Standard LP research sources

Use these Japanese galleries as discovery starting points. They are not mandatory references for every job. Select examples that match the submitted industry, audience, desired impression, color direction, and mobile requirements.

| Gallery | URL | Primary use |
|---|---|---|
| SANKOU! | https://sankoudesign.com/category/lp/ | Broad LP visual and industry references |
| Site Advance | https://site-advance.info/ | Japanese LP composition and visual references |
| LP Archive | https://rdlp.jp/lp-archive/ | Industry, color, and taste-based LP discovery |
| Smartphone Landing Page | http://smartphone-landingpage.info/ | Smartphone-first hierarchy and presentation |
| Web Design Book | http://design.web-hon.com/ | Japanese web and LP design references |
| Responsive Web Design JP | https://responsive-jp.com/ | Responsive page behavior and layout references |
| Web Design Clip LP | https://lp.webdesignclip.com/ | Landing-page visual and layout discovery |

## Research rules

1. Inspect references supplied in the form first.
2. Search the standard galleries for examples close to the job's industry and audience.
3. Record the direct URL of each selected example when the gallery exposes one.
4. Explain the specific observation: hierarchy, section rhythm, spacing, typography, color, imagery, or mobile behavior.
5. Separate observations from proposed use. Do not describe a gallery page as evidence for claims about the client's market.
6. Do not copy text, images, illustrations, logos, or an entire visual composition.
7. Record inaccessible pages and continue with accessible sources rather than inventing observations.
