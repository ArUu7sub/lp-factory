# Standard LP research sources

Use the first five sources for every LP job before settling the visual direction. Record each check even when a source is inaccessible or no candidate is adopted. Then use the optional Japanese galleries and user-supplied URLs to narrow the search by industry, audience, desired impression, color direction, and mobile requirements.

## Required visual checks

| Source | URL | Primary use |
|---|---|---|
| SANKOU! | https://sankoudesign.com/ | Japanese LP hierarchy, typography, color, and visual tone |
| 81-web.com | https://81-web.com/ | Japanese website composition, spacing, and responsive references |
| Web Design Clip | https://webdesignclip.com/ | Japanese web/LP visual and layout discovery |

| 21st.dev | https://21st.dev/ | Component and interaction patterns; do not copy components unchanged |

For wireframe work, also check and record the Xserver wireframe guide, the configured Pinterest wireframe board, and the configured Google image-search query. Treat dynamic search results as references only when the exact viewed page or image is recorded. If a source is inaccessible or login-gated, record it as `UNVERIFIED`; never invent an observation.

## Research rules

1. Inspect references supplied in the form first.
2. Search the standard galleries for examples close to the job's industry and audience.
3. Record the direct URL of each selected example when the gallery exposes one.
4. Explain the specific observation: hierarchy, section rhythm, spacing, typography, color, imagery, or mobile behavior.
5. Separate observations from proposed use. Do not describe a gallery page as evidence for claims about the client's market.
6. Do not copy text, images, illustrations, logos, or an entire visual composition.
7. Record inaccessible pages and continue with accessible sources rather than inventing observations.
8. For every required source, record the candidate or `UNVERIFIED`, useful pattern, selected/rejected decision, fit rationale, and originality/accessibility concern. Writing only “checked” is insufficient.
