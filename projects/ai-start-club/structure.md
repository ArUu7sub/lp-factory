## デザイン仕様

### カラーパレット
```css
--color-primary: #F59E0B;      /* アンバーオレンジ（メイン） */
--color-primary-dark: #D97706; /* ダークアンバー（ホバー） */
--color-secondary: #FFFBF0;    /* クリームホワイト（背景サブ） */
--color-accent: #2D6A4F;       /* 深みのある緑（自然・地方） */
--color-accent-light: #52B788; /* ライトグリーン */
--color-text: #3D2B1F;         /* ダークブラウン（メインテキスト） */
--color-text-muted: #7C6B5E;   /* ミュートブラウン（サブテキスト） */
--color-bg: #FFFFFF;           /* 白背景 */
--color-bg-cream: #FFFBF0;     /* クリーム背景 */
--color-bg-warm: #FEF3C7;      /* 温かみのある薄黄 */
```

### フォント
- 見出し：Noto Serif JP（明朝タッチで温かみ）
- 本文：Noto Sans JP（読みやすいゴシック）
- アクセント：Zen Maru Gothic（丸みゴシック）

### 共通スタイル
- ボタン：border-radius 50px（大きな丸角）
- カード：border-radius 16px・box-shadow 柔らかいもの
- セクション間：padding 80px 0
- 見出し↔本文：margin-bottom 16px
- カード内要素間：margin 8〜12px

### アニメーション
- ページロード：フェードインスライドアップ（0.6s ease）
- スクロール連動：Intersection Observer でフェードイン
- カードホバー：translateY(-4px) + shadow強化（0.2s ease）
- CTAボタンホバー：scale(1.03) + background-color遷移
